# Cybersecurity Labs

This directory will contain smaller practical exercises that demonstrate continuous cybersecurity learning outside the main projects.

## Planned Labs

- Wireshark traffic analysis
- Nmap reconnaissance in controlled environments
- Linux security exercises
- Network troubleshooting
- Vulnerability assessment fundamentals
- Web application security fundamentals
- OWASP Top 10 learning exercises
- Security documentation and incident-analysis exercises
- GRC and compliance notes
- Cloud security fundamentals
- AI security research and experiments

## Lab Documentation Standard

Each lab should document:

1. Objective
2. Environment
3. Tools used
4. Methodology
5. Commands/configuration where appropriate
6. Observations
7. Security implications
8. Lessons learned

> Labs are intended for controlled and authorized environments only.
