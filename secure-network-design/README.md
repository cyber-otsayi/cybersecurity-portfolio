# Secure Small Network Design

## Overview

A Cisco Packet Tracer security simulation focused on designing, segmenting, configuring, and testing a small network environment.

## Objective

- Design a small office-style network.
- Apply basic network segmentation and security controls.
- Configure routing, NAT, DHCP, and firewall concepts.
- Test connectivity between network zones.
- Troubleshoot common network and security configuration issues.

## Technologies & Tools

- Cisco Packet Tracer
- Cisco ASA
- VLANs
- NAT
- DHCP
- Routing
- Firewall fundamentals
- Nmap
- Wireshark

## Network Components

The simulated environment includes network infrastructure and end devices representing an office environment, with separate security zones considered for internal and guest traffic.

## Methodology

1. Designed the network topology in Cisco Packet Tracer.
2. Connected the router, firewall, switch, server, workstation, and IoT/guest devices.
3. Configured VLAN and network addressing concepts.
4. Configured routing and default gateways.
5. Applied NAT and DHCP configurations.
6. Configured Cisco ASA interfaces and security zones.
7. Tested connectivity between devices and network segments.
8. Investigated failed connectivity and corrected configuration issues.
9. Used network-security tools and packet analysis concepts to validate the environment.

## Security Concepts Demonstrated

- Network segmentation
- Trust boundaries
- Firewall policy concepts
- NAT
- Least-privilege communication between zones
- Network troubleshooting
- Controlled access between office and guest environments

## Results

The project provided practical experience designing and troubleshooting a segmented network. Testing showed how routing, VLAN configuration, firewall policies, addressing, NAT, and gateways interact to determine whether traffic can successfully move between network zones.

## Challenges & Lessons Learned

The lab involved troubleshooting interface configuration, IP addressing, VLANs, ASA security zones, NAT, and connectivity problems. These challenges strengthened practical understanding of network configuration and firewall troubleshooting.
